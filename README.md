# 🌑 Dark Generative Art Laboratory

This repository contains experimental generative art projects coded using p5.js (JavaScript), simulating various forms.

---

## ⚡ Gallery Contents

The project is structured with a multi-experiment architecture accessible via the main gallery menu (`index.html`) in the root directory:

-   **Deney 1:** İlk Kaos (`sketch-1.js`) 
-   **Deney 2:** Çekirdek (`sketch-2.js`) 
-   **Deney 3:** Siluet (`sketch-3.js`) 
-   **Deney 4:** Kabus(`sketch-4.js`) 
-   **Deney 5:** Derin Kabus(`sketch-5.js`) 
-   **Deney 6:** Yabancı(`sketch-6.js`) 
-   **Deney 7:** Tanrısal (`sketch-7.js`) 
-   **Deney 8:** Manik (`sketch-8.js`) 

---

## 🛠️ Setup and Execution

To run these projects live on your computer and experience those mental simulations:

1. Clone or download this repository to your computer.
2. Open the folder with **VS Code**.
3. Install the **Live Server** extension on VS Code.
4. Right-click on the **`index.html`** file in the root directory and select **"Open with Live Server"**.
5. Click on your desired mental layer from the opened browser gallery.
