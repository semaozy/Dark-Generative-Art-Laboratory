# 🌑 Dark Generative Art Laboratory

Bu repository; p5.js (JavaScript) kullanılarak kodlanmış, farklı formları simüle eden deneysel generatif sanat projelerimi barındırır. 

---

## ⚡ Galeri İçeriği

Proje, kök dizindeki ana galeri menüsü (`index.html`) üzerinden erişilebilen çoklu deney mimarisiyle kurulmuştur:

*   **Deney 1:** İlk Kaos (`sketch-1.js`) 
*   **Deney 2:** Çekirdek (`sketch-2.js`) 
*   **Deney 3:** Siluet (`sketch-3.js`) 
*   **Deney 4:** Kabus(`sketch-4.js`) 
*   **Deney 5:** Derin Kabus(`sketch-5.js`) 
*   **Deney 6:** Yabancı(`sketch-6.js`) 
*   **Deney 7:** Tanrısal (`sketch-7.js`) 
*   **Deney 8:** Manik (`sketch-8.js`) 

---

## 🛠️ Kurulum ve Çalıştırma

Bu projeleri kendi bilgisayarınızda canlı olarak çalıştırmak ve o zihinsel simülasyonları deneyimlemek için:

1. Bu repository'yi bilgisayarınıza klonlayın veya indirin.
2. Klasörü **VS Code** ile açın.
3. VS Code üzerinde **Live Server** eklentisini kurun.
4. Ana dizindeki **`index.html`** dosyasına sağ tıklayıp **"Open with Live Server"** seçeneğini seçin.
5. Açılan tarayıcı galerisinden dilediğiniz zihinsel katmana tıklayın.
